# 시트 스냅

구글 시트 링크를 붙여넣고 **뽑을 범위의 양 끝 모서리를 찍으면** 그 부분만 고화질 PNG로 저장하는 정적 웹페이지입니다.

## 두 가지 모드

| | 간편 모드 (키 없음) | 서식 모드 (API 키) |
|---|---|---|
| 값 | ✅ | ✅ |
| 배경색 · 글자색 · 굵게/기울임 · 글꼴 | ❌ | ✅ |
| 테두리 · 셀 병합 · 정렬 · 줄바꿈 | ❌ | ✅ |
| 열 너비 · 행 높이 · 숨긴 행/열 | 추정 | ✅ 시트 그대로 |
| 체크박스 | TRUE/FALSE 글자 | ✅ 체크박스 모양 |
| 탭 선택 | 링크의 `gid`로만 | ✅ 드롭다운 |

어느 쪽이든 시트는 **공유 → 링크가 있는 모든 사용자 → 뷰어**로 되어 있어야 합니다.

## API 키 발급 (서식 모드)

1. [Google Cloud Console](https://console.cloud.google.com/)에서 프로젝트를 하나 만듭니다.
2. **API 및 서비스 → 라이브러리**에서 `Google Sheets API`를 찾아 **사용**을 누릅니다.
3. **API 및 서비스 → 사용자 인증 정보 → 사용자 인증 정보 만들기 → API 키**.
4. 만든 키의 **키 제한**을 꼭 설정합니다.
   - 애플리케이션 제한: **웹사이트** → `https://oocumu.github.io/*`
   - API 제한: **Google Sheets API**만 선택
5. 페이지의 “API 키 설정”에 붙여넣고 **저장**하면 그 브라우저에 기억됩니다.

## 범위 지정 — 모서리 두 개 찍기

뽑을 범위의 **양 끝 모서리 두 칸**을 찍습니다.

- **입력**: `I 23`, `i23`, `I,23` 모두 됩니다. 어느 쪽이 위/아래든 상관없어요.
- **클릭**: 시트를 불러오면 행·열 번호가 붙은 미리보기가 나와요. **좌클릭 = 1번**, **우클릭 = 2번** 모서리.
  휴대폰은 탭할 때마다 1번 → 2번 순서로 찍혀요.
- **자동으로 찍기**: 글자가 있는 곳을 기준으로, 바깥으로 최대 6칸 안에서 끝나는 테두리·색 틀까지만 넣어서 추정합니다.
  시트 전체에 깔린 배경색처럼 끝없이 이어지는 장식은 무시해요. 추정이 틀리면 한쪽 모서리만 다시 찍으면 됩니다.

## 옵션

- **배율** 1x~4x: 2x면 시트 화면의 2배 해상도. 너무 큰 시트는 브라우저 캔버스 한계(한 변 16,384px) 때문에 자동으로 배율을 낮추고 표시해 줍니다.
- **격자선**: 시트에서 격자선을 숨겼다면 체크해도 그려지지 않습니다.
- **빈 배경 투명**: 색이 없는 칸을 투명하게 둡니다.
- **바깥 여백**: 이미지 가장자리에 여백을 줍니다.

## 아직 안 되는 것

- 차트, 그림(삽입 이미지, `IMAGE()` 함수), 드롭다운 칩 모양
- 한 셀 안에서 일부 글자만 다른 서식(부분 굵게 등) — 셀 전체 서식으로 그려집니다
- 텍스트 회전
- “웹에 게시” 링크(`/d/e/…`) — 편집 링크(`/d/…/edit`)를 넣어야 합니다

글꼴은 시트에서 쓴 구글 폰트를 자동으로 불러오고, 없는 글꼴이나 한글은 Noto Sans KR로 대신 그립니다.
